## Definitions

- **Fabricated fact**: a specific claim with no source available to the system. This week any concrete schedule, opening hour, fee, phone number, document list, ticket status or completed action is unsupported.
- **Unfaithful**: contradicts the given input, context or instructions (e.g. claims a ticket was created when only a draft is possible, adopts an injected label, discloses what it must not).
- **Reasoning error**: wrong inference from correct facts (e.g. wrong urgency class under `docs/priority_policy.md` v0.3).
